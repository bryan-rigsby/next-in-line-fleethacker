🏗️ Zero-Cost Flank Speed M365 Architecture (Standard Connectors Only)

1. SharePoint Lists (Data Layer)

Two standard lists hosted on NRC Houston's SharePoint site: NRC_Config_Departments (editable settings) and NRC_Queue_Tickets (permanent visit records).

2. Power Apps Canvas / Web Part

Single QR link opens the mobile Sailor view. Staff and Quarterdeck views embed directly on SharePoint pages using standard M365 licenses (zero Dataverse or premium licensing).

3. Power Automate Standard Flow

Triggers when Status changes to Called or Transferred. Sends an automated Flank Speed Teams message and Outlook email with the room & preset message.

4. Any-NRC Portability

Because departments, rooms, services, document links, and message presets live in an editable SharePoint list, any Navy Reserve Center can tailor this app without code.
