Queue Configuration

Use the Microsoft editors for changes to the form, list, and flows. Access depends on your permissions in each tool.

Reporting locations

In Site contents, create a list named QueueConfiguration. Add a single line of text column named ReportingRoom. Create one row per department code, using Title for the code. Give dashboard users read access and maintainers edit access.

    Tickets list

    Open the SharePoint site, then open Site contents → Tickets. Use List settings to review columns and choice values. Coordinate column changes with the dashboard and any flow that reads or writes those fields.

    Intake form

    In Microsoft Forms, open the intake form from your forms or the owning group. Update the questions, department choices, and branching. Use Preview to test each changed branch.

    Power Automate

    Open the intake flow and review how form answers map to Tickets fields. If department choices changed, update the matching cases and the dashboard department codes. Submit a test response, check the resulting ticket, then call it to verify the notification.
